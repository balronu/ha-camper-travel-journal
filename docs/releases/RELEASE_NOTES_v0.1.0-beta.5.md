# Camper Travel Journal v0.1.0-beta.5

## Visueller Lovelace-Karteneditor

- Summary- und Manager-Card erscheinen im Home-Assistant-Kartenkatalog.
- Beide Karten besitzen einen grafischen Konfigurationseditor.
- Konfigurierte Camper werden über eine authentifizierte Integration-WebSocket-API geladen.
- Bei genau einem eingerichteten Camper wird die Config-Entry-ID automatisch vorausgewählt.
- Bestehende YAML-Konfigurationen mit `vehicle_id` bleiben kompatibel.
- Deutsche und englische Editor-Texte sowie Dark-Mode-kompatible Darstellung.

## Branding

- Lokale Home-Assistant-Branding-Assets liegen unter `custom_components/camper_travel_journal/brand/`.
- Der offizielle lokale Branding-Weg für moderne Home-Assistant-Versionen wird dokumentiert.

## Scope

Pre-Release für kontrollierte Entwicklungstests. Keine produktiven Home-
Assistant-, Proxmox-, Recorder- oder Dashboard-Änderungen.
