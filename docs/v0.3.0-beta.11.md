# v0.3.0-beta.11 – Karten, Ortsnamen und responsive Kostenverwaltung

Beta.11 builds on the local, authenticated GPX workflow from beta.10. It does
not install anything in Home Assistant and does not migrate or rewrite a
productive database.

## Location resolution and privacy

Drive endpoint labels use this order: a manually stored drive label, a nearby
confirmed place already stored in the journal, then the exact coordinate
fallback. The implementation does not call a geocoding service and does not
send GPS coordinates to an external provider. Consequently, a new endpoint
without a matching saved place remains a coordinate until the user adds or
edits a place name. This is intentional and keeps GPX import and offline use
independent of network availability.

## Maps in the PDF

The PDF export now receives the persisted route segments and draws the actual
GPX points on a neutral, geographic background. It is deterministic and
offline-capable, includes start/destination markers and a legend, and never
downloads map tiles. A report without valid route points shows a localized
empty-state message instead of a misleading map.

The interactive Lovelace map still treats configured tile providers as an
explicit opt-in. It fits the route only after the map container has a valid
size, so hidden tabs and accordions no longer leave a route at the world view.

## Data compatibility

Canonical expense category IDs remain unchanged. Historical localized category
values are normalized only in the editor; unknown values remain visible and
are never silently converted to camping. Existing dates, optional wall-clock
times, distances, raw GPX points and manually entered labels are preserved.
