# v0.3.0-beta.12 – Expense display, home zone and endpoint labels

Beta.12 fixes the productive expense-editor category selection, wraps long
metric labels safely, and formats expense calendar dates without timezone
conversion. Stored ISO dates and capture timestamps remain unchanged.

## Location resolution and privacy

Endpoint labels use this order: manually maintained name, a configured
Home Assistant zone such as `zone.home` within the selected radius, an
unambiguous confirmed stay from the same trip, a cached result, and finally
the coordinate fallback. Manual labels are never overwritten. No stay is
created automatically and GPX raw points are never changed.

External reverse geocoding is disabled by default. If explicitly enabled, only
relevant endpoints rounded to three decimal places are queried. Results are
cached in memory for the current runtime, with a one-second rate limit and a
timeout. Import and PDF export remain fully usable offline. No API keys are
sent to the frontend or written to logs; provider terms and attribution must
be reviewed before enabling a provider.

## PDF travel map

The PDF map remains deterministic and offline-capable, using a neutral
geographic background without third-party map tiles. Start/destination labels
and confirmed overnight places are shown beside the actual GPX tracks and in
the legend. Invalid markers are skipped; long labels are wrapped inside the map
with deterministic collision avoidance. Reports with no valid GPS points show a
localized fallback message; coordinates remain the
conservative fallback when no safe place name exists.
