# v0.3.0-beta.13 – Display and PDF corrections

This beta fixes three production-observed display issues:

- The statistics tile uses the compact “Overnights” label while keeping all five metrics unchanged.
- The central costs view has one disclosure level containing the count, add button, expense list, and total.
- The offline PDF travel map deterministically groups identical labels at the same rendered location. Start, destination, and overnight roles remain represented by the marker; distinct nearby places are not merged merely because their names are similar.

These display changes do not modify GPX raw points, drives, stays, kilometers, or expenses.
